UNIT 1 Data Warehouse & Ingestion Architecture
ETL • Schema • Pushdown
PostgreSQL 18 Relational Data Warehouse Pipeline O(1) Client Memory
  • Relational Warehouse Design: Normalized 20-attribute schema enforcing constraints (Attendance ∈ [0, 100]%, Sleep ∈ [0, 24]h, Scores ∈ [0, 100]).
  • Composite B-Tree Indexing: Dedicated B-Tree indexes on (Exam_Score, Attendance) optimize range filtering for fast analytics.
  • Descriptive to Prescriptive Flow: Aggregated population metrics feed predictive modeling to target underperforming cohorts for intervention.
